# TeaPro ERP — English User Manual

## First use

Complete setup, create the first administrator, store the recovery key, choose printers and a backup location. There is no public registration or default password.

## Daily leaf collection

1. Open **Leaf Collection POS** and select supplier and estate/location.
2. Enter gross weight and approved bag, moisture and other deductions.
3. Confirm net weight, rate, allowances and financial deductions.
4. Select cash, bank, credit, partial or pending settlement.
5. Select **Save and print**. The transaction commits before printing. If printing fails, use **Reprint**; do not create another bill.

## Corrections

Posted transactions cannot be deleted normally. An authorized user selects **Correction** or **Void**, records a reason and re-authenticates. The original remains in audit history.

Register suppliers and rates, review collection history, then verify advances/deductions/outstanding balances before settlement. For payroll, review attendance, weights, wages, overtime, bonuses, advances and deductions before posting.

At day end, reconcile cash/bank/credit totals, close the cash book and create a verified backup. Lock or sign out when leaving the computer. The language control switches UI between English and Sinhala without changing stored business data.
