# TeaPro ERP — සිංහල පරිශීලක අත්පොත

## පළමු භාවිතය

පළමු සැකසුම සම්පූර්ණ කර පරිපාලක ගිණුම සාදන්න. ප්‍රතිසාධන යතුර ආරක්ෂිතව තබා මුද්‍රණ යන්ත්‍ර සහ උපස්ථ ෆෝල්ඩරය සකසන්න. පෙරනිමි මුරපදයක් හෝ පොදු ලියාපදිංචියක් නොමැත.

## දෛනික දළු එකතු කිරීම

1. **දළු එකතු කිරීමේ POS** විවෘත කර සැපයුම්කරු, වත්ත සහ ස්ථානය තෝරන්න.
2. දළ බර, බෑග් බර, තෙතමන සහ අනෙකුත් අනුමත අඩු කිරීම් ඇතුළත් කරන්න.
3. ශුද්ධ බර, කිලෝ මිල, දීමනා සහ මුදල් අඩු කිරීම් තහවුරු කරන්න.
4. මුදල්, බැංකු, ණය, අර්ධ හෝ පසුව ගෙවීම තෝරන්න.
5. **සුරැක මුද්‍රණය කරන්න** තෝරන්න. මුද්‍රණයට පෙර ගනුදෙනුව සුරකී. මුද්‍රණය අසාර්ථක නම් නව බිල්පතක් නොසාදා **නැවත මුද්‍රණය** භාවිත කරන්න.

සුරැකි මූල්‍ය ගනුදෙනුවක් සාමාන්‍යයෙන් මැකිය නොහැක. අවසර ඇති පරිශීලකයා හේතුවක් සමඟ නිවැරදි කිරීමක් හෝ අවලංගු කිරීමක් සටහන් කළ යුතුය; මුල් වාර්තාව විගණන ඉතිහාසයේ පවතී.

දවස අවසානයේ මුදල්/බැංකු/ණය එකතු සැසඳීම, මුදල් පොත අවසන් කිරීම සහ තහවුරු කළ උපස්ථයක් සාදන්න. පරිගණකයෙන් ඉවත්වන විට තිරය අගුළු දමන්න හෝ ඉවත් වන්න.
